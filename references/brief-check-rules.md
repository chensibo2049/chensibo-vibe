# 需求体检规则（brief check rules）

> 出处：官网 AI 小课堂工具 BriefTool.vue 的真实判定逻辑（2026-10-03 抽取），
> 同一套方法论即 Skill 的 `brief` 命令实现基准：命中任一正则 = 该要素已具备。

## 做什么

- 提示语：要做的东西（功能 / 页面 / 系统）
- 补全模板：`做一个 <产品/功能>，包含 <核心功能点>`
- 命中正则（任一即算具备）：
  - `/做|开发|搭建|改|加|实现|设计|系统|平台|页面|程序|小程序|网站|应用|工具|功能/`

## 给谁用

- 提示语：目标用户与使用场景
- 补全模板：`给 <谁> 用，在 <什么场景> 用`
- 命中正则（任一即算具备）：
  - `/用户|学生|老师|客户|学员|玩家|读者|给谁|面向|机构|馆|单位|企业|商家|团队/`

## 期望时间

- 提示语：期望上线 / 交付的时间点
- 补全模板：`期望 <时间点> 前上线 / 交付`
- 命中正则（任一即算具备）：
  - `/\d+\s*月|\d+\s*日|\d+\s*号|本周|下周|月底|年底|之前|以内|前上线|截止|排期/`

## 参考与预算

- 提示语：参考对象与预算区间（给一个即可）
- 补全模板：`参考 <产品/风格>，预算 <区间或可谈>`
- 命中正则（任一即算具备）：
  - `/预算|报价|价格|费用|多少钱|元|万|参考|类似|对标|像\s*\S+\s*一样/`
